# Формат файла

## Документ

Макет — один JSON-документ (`*.wireframe.json`). В нём имя и идентификатор проекта, экраны (`layers`)
с блоками, варианты экранов, переиспользуемые компоненты, тема макета и встроенные изображения.
Сериализатор — source-generated `System.Text.Json`, поэтому формат работает при trimming WebAssembly.

- **Экспорт** пишет читаемый JSON с отступами, **хранилище** браузера — компактный.
- Записывается только хранимое состояние: вычисляемые представления (например, «все блоки всех
  экранов») и поля блоков, равные значениям по умолчанию, пропускаются, а чтение их восстанавливает.
  Поэтому большой макет занимает единицы мегабайт, а не десятки.
- Старые файлы, где вычисляемые поля ещё записаны, читаются; эти поля игнорируются.

## Версии схемы

Текущая схема — **9** (`DraftDocument.CurrentSchemaVersion`). Схемы 1–8 мигрируют при чтении. Файл
более новой версии Draftline отклоняется с сообщением, в котором названы обе версии, — вместо того
чтобы открыться с молча потерянными полями.

Повреждённый документ при чтении восстанавливается: недостающие экраны, битые ссылки и недопустимые
значения заменяются, чтобы редактору не приходилось защищаться от недописанного файла. Файл, который
вовсе не является макетом Draftline, отклоняется.

## Изображения

Вставляются PNG, JPEG, GIF и WebP до 5 МБ. Крупные картинки уменьшаются до 2048 px и примерно 2 МБ.
Изображения встраиваются в документ, поэтому выгруженный JSON самодостаточен.

## Хранение в браузере

| Ключ | Содержимое |
| :-- | :-- |
| `draftline.index` | Список проектов: идентификатор, имя, последнее изменение, число блоков |
| `draftline.project.<id>` | Документ одного проекта (компактный JSON) |
| `draftline.last` | Проект, который открыть при следующем запуске |

Ключи хранятся в IndexedDB. Импорт записывает проект, список и последний открытый проект одной
транзакцией, поэтому неудачный импорт оставляет каталог как был. Записи прежних версий из
`localStorage` переносятся транзакционно: оригинал удаляется только после успешной записи. Если
браузер запрещает хранилище, редактор работает в памяти и предупреждает об этом. Ошибка квоты не
снимает отметку о несохранённых правках.

## Офлайн

Опубликованное приложение регистрирует service worker. При установке он кеширует всю сборку по списку
ресурсов SDK (`service-worker-assets.js`) и отвечает по стратегии cache-first. Имя кэша —
`draftline-<assetsManifest.version>`, поэтому новый релиз заменяет прежний кэш. Сервер разработки ничего
не кеширует. Roboto для официальной темы Material загружается из Google Fonts; без сети браузер
использует доступный запасной шрифт.

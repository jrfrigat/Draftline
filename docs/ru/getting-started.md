# Начало работы

## Открыть Draftline

- **В браузере**: <https://jrfrigat.github.io/Draftline/>. Ничего устанавливать не нужно; браузер может
  установить его как приложение (PWA), и тогда оно открывается без сети.
- **Локально**: при установленном .NET 10 SDK

  ```powershell
  dotnet run --project src/Draftline.App
  ```

  и откройте HTTP-адрес из вывода команды. Сервер разработки не кеширует приложение, поэтому
  обновление страницы всегда показывает последнюю сборку.

## Первый макет

1. Новый проект открывается с одним пустым экраном. Панель **Блоки** слева перечисляет все виды
   блоков; нужный удобно найти через поле поиска.
2. Перетащите блок на холст или нажмите его, чтобы поставить в свободное место. Выделите блок, чтобы
   изменить его текст, данные и состояния в панели **Свойства** справа.
3. Экраны добавляются в панели **Экраны**. Кнопка, ссылка или пункт меню может открыть другой экран
   или показать его диалогом: переход выбирается в свойствах блока.
4. Команды собраны на ленте: **Файл** (импорт и экспорт), **Макет** (поиск, отмена и повтор), **Блок**
   и **Вид** (темы, просмотр, панели).

Каждое изменение сохраняется в браузер автоматически, через мгновение после правки; строка состояния
показывает, удалось ли сохранение.

## Просмотр

**Вид → Просмотр** показывает макет так, как его увидит человек: работают переходы, флажки, вкладки,
выпадающие списки и ветки деревьев меняют состояние, а редактировать ничего нельзя. **К редактору**
возвращает обратно. Состояния просмотра временные и документ не меняют.

## Файлы

- **Файл → Выгрузить JSON** записывает весь макет вместе с изображениями в один переносимый файл.
- **Файл → Загрузить JSON** открывает такой файл новым проектом. Если проект из файла уже есть в этом
  браузере, он откроется копией с новым идентификатором: ничего не перезаписывается. Для большого
  файла показывается прогресс чтения, проверки, сохранения и открытия.
- **SVG, PNG и PDF** выгружают текущий экран или сразу все экраны (для SVG и PNG — ZIP-архивом).
  В PDF переходы остаются кликабельными ссылками между страницами.

## Где хранятся данные

Проекты лежат в IndexedDB этого браузера, и ничего не покидает ваш компьютер. Очистка данных сайта
удаляет их, а приватное окно может их вовсе не сохранить: тогда Draftline предупреждает, что работает
только в памяти. Чтобы сохранить копию или перенести макет, выгрузите JSON. См. [Формат файла](file-format.md).

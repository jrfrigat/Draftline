# Draftline

Автономный редактор вайрфреймов на Blazor WebAssembly (.NET 10) и Flare 0.44.0.
Приложение работает в браузере без backend и аккаунтов.

## Возможности

- 57 видов блоков, редактирование текста, данных и состояний, вкладки с содержимым, меню и формы.
- Несколько экранов, переходы и диалоги; интерактивный просмотр с временными состояниями.
- Группы, буфер блоков, блокировка, скрытие, выравнивание, история отмены, поиск по макету.
- Локальные изображения и иконки, компоненты и независимые варианты экранов.
- Независимые темы конструктора и макета: Fluent UI 2, Material Design 3 Expressive; черновой вид макета.
- Масштаб, вписывание по ширине, режим «Рука», клавиатурный выбор и перемещение блоков.
- Переносимый JSON, SVG, PNG и PDF. PDF содержит растровые страницы и кликабельные переходы.

## Сборка и запуск

```sh
dotnet build Draftline.slnx
dotnet run --project src/Draftline.App
```

Откройте HTTP-адрес из вывода команды. nuget.config содержит nuget.org и локальный фид Flare
C:\Job\Projects\FrigaT\Flare\artifacts; восстановление без сети требует уже доступных пакетов.

## Проверки

```sh
dotnet test --solution Draftline.slnx
dotnet build Draftline.slnx -c Release
dotnet publish src/Draftline.App -c Release
```

tests/Draftline.App.Tests — xUnit v3 / Microsoft.Testing.Platform: история, схемы 1–9,
повреждённый JSON, геометрия, SVG, каталог, импорт, автосохранение, жесты, варианты и кэш рисунков.
Перед коммитом и публикацией проверяйте синтаксис JavaScript (PowerShell, Node.js):

```powershell
Get-ChildItem src/Draftline.App/wwwroot -Recurse -Filter *.js | ForEach-Object {
    node --check $_.FullName
    if ($LASTEXITCODE -ne 0) { throw 'Ошибка синтаксиса JavaScript' }
}
```

## Данные и офлайн

Документы и каталог хранятся локально в IndexedDB. Прежние записи localStorage переносятся
транзакционно: оригиналы удаляются только после успешной записи. При запрете хранилища приложение
работает во временной памяти и предупреждает об этом; выгрузите JSON перед закрытием вкладки.
Ошибка квоты не снимает отметку о несохранённых правках.

Формат документа — схема 9. Старые схемы мигрируют при чтении; более новая неизвестная схема
отклоняется. JSON использует source-generated System.Text.Json для совместимости с WASM trimming.
Хранилище использует компактный JSON, экспорт — читаемый. Изображения входят в переносимый файл;
при вставке принимаются PNG/JPEG/GIF/WebP до 5 МБ, при необходимости уменьшаются до 2048 px и 2 МБ.

Офлайн работает у опубликованной PWA после первой успешной загрузки и установки service worker.
SDK формирует список ресурсов и версию; имя кэша — draftline-<assetsManifest.version>.
Оболочка и ресурсы сборки кешируются при установке, затем используется cache-first.
В режиме разработки service worker не кеширует приложение. Roboto официальной темы Material
загружается из Google Fonts; без сети браузер использует доступный запасной шрифт.

## Состав

src/Draftline.App: Model — домен и геометрия; Services — сессия, история, хранение и экспорт;
Components/Pages — интерфейс; Theming — независимое оформление макета; wwwroot — локальные ресурсы.
tests/Draftline.App.Tests: спеки ядра и регрессий. Правки самой библиотеки Flare живут в проекте Flare.

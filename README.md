# Draftline

Лёгкий автономный редактор low-fidelity вайрфреймов: схематичный каркас экрана из готовых блоков за
несколько минут. Аналог Balsamiq по духу, но как **клиентское PWA**: Blazor WebAssembly, библиотека
компонентов [Flare](https://www.nuget.org/packages/Flare.Blazor), никакого backend.

## Что это

- **Low-fi конструктор.** Перетаскивание, изменение размеров и свободное позиционирование схематичных
  блоков: панель, текст, заголовок, кнопка, поле ввода, многострочное поле, чекбокс, радио, выпадающий
  список, список, изображение-плейсхолдер, разделитель.
- **Никакого визуального шума.** Прямые углы, штриховка вместо картинок, один акцентный цвет темы.
  Градиентов, радиусов и pixel-perfect настроек здесь нет намеренно: внимание остаётся на структуре
  экрана и пользовательском сценарии, а не на подборе цветов.
- **Offline-first.** Приложение — PWA: манифест, сервис-воркер и кэш оболочки. Оно запускается и
  работает без сети.
- **Всё локально.** Проекты и документы живут в браузере (localStorage), без сервера и без аккаунтов.
- **Обмен файлами.** Макет выгружается в JSON (и загружается обратно) и в SVG.

## Состав решения

```
Draftline.slnx
src/Draftline.App   приложение (Blazor WebAssembly, net10.0, PWA)
```

Внутри приложения:

| Папка | Что там |
| :-- | :-- |
| `Model/` | домен: документ, блоки, геометрия, сериализация |
| `Services/` | хранение, автосохранение, история, экспорт SVG, файловые операции |
| `Components/` | палитра блоков, холст, рендер блока, инспектор свойств |
| `Layout/`, `Pages/` | оболочка приложения и страница редактора |
| `wwwroot/` | `index.html`, манифест, сервис-воркеры, `css/`, `js/` |

## Сборка и запуск

```sh
dotnet build Draftline.slnx
dotnet run --project src/Draftline.App
```

`nuget.config` держит два источника: nuget.org и папку собранных пакетов Flare
(`C:\Job\Projects\FrigaT\Flare\artifacts`), поэтому рестор проходит и на машине без сети.

## Технические решения

- **Flare 0.44.0** (`Flare.Blazor` + `Flare.Theme.MaterialDesign3Expressive`), тема подключается в
  `Program.cs` через `AddFlare`, а первый кадр красит `flare-bootstrap.js` из `<head>` — тот же
  набор темы, палитры и режима, что и в коде.
- **Версионирование документа** — поле `schemaVersion`: файл макета должен открываться и через год.
- **Сериализация** — `System.Text.Json` с source-generated контекстом: в WASM рефлексия по типам
  ненадёжна, контекст делает JSON-контракт явным и безопасным для trimming.
- **Геометрия и взаимодействие** — чистые классы без DOM, поэтому покрыты спеками; JS отвечает
  только за события указателя.
- **Офлайн** — свой сервис-воркер: кэш оболочки на установке, cache-first для статики, возврат к
  `index.html` при обрыве сети. Имя кэша меняется руками (`draftline-v1`), это и есть версия сборки.

## Что не входит в первую версию

Backend, аккаунты, совместная работа, импорт чужих форматов, pixel-perfect темы и стили,
экспорт в PNG/PDF. Тестового проекта тоже нет — по решению от 14.10.2026 спеки отложены, но вся
логика (модель, геометрия, JSON, SVG) написана как обычные классы без DOM и без рендера, чтобы
спеки можно было добавить позже, не переписывая приложение. Правки самой библиотеки Flare — не
здесь, а в проекте Flare.
